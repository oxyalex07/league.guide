## Verification method

The content check compares generated output with the revised canonical Markdown, preserving ordered text, captions and source notes. It intentionally does not require equality with the superseded advice-title package. The build checks names/slugs against concepts.json. Browser checks cover all ten concepts and legacy aliases at desktop, mobile and narrow widths, plus filters, search, related links, history, image loading, responsive variants and overflow. Manual integration review supplies semantic concept/figure alignment; automated text equality alone does not prove factual quality.
